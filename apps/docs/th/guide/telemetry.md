# สิ่งที่ SnapOtter เก็บรวบรวม {#what-snapotter-collects}

Anonymous Product Analytics ผู้ดูแลระบบเป็นผู้ตั้งค่าให้ทั้งอินสแตนซ์ อินสแตนซ์ใหม่จะถามเมื่อเปิดใช้ครั้งแรกและจะไม่ส่งอะไรจนกว่าจะมีคนตอบ คุณเปลี่ยนได้ทุกเมื่อที่ Settings > System > Privacy

เมื่อเปิดการวิเคราะห์ SnapOtter จะส่งให้ PostHog ว่ามีเครื่องมือและ pipeline ใดทำงาน ใช้เวลานานเท่าใด สำเร็จหรือไม่ รหัสข้อผิดพลาด และจำนวนไฟล์ พร้อมกับ ID แบบไม่ระบุตัวตนของอินสแตนซ์ เวอร์ชัน สถาปัตยกรรม CPU ระบบปฏิบัติการ ประเภทการติดตั้ง และมี GPU หรือไม่ รายงานข้อขัดข้องจะถูกส่งไปยัง Sentry โดยตัดชื่อไฟล์ พาธ อีเมล และค่าที่อยู่ในเครื่องหมายคำพูดออกแล้ว SnapOtter จะไม่ส่งไฟล์ของคุณ ชื่อหรือพาธของไฟล์ เนื้อหาในไฟล์ ผลลัพธ์ OCR หรือข้อความที่ดึงออกมา เมทาดาทาของรูปภาพ หรือตัวตนบัญชีของคุณเลย PostHog และ Sentry เป็นปลายทางเพียงสองแห่งที่ส่งข้อมูลไป และเมื่อปิดการวิเคราะห์จะไม่ส่งอะไรไปยังทั้งสองแห่ง

## ตัวเลือกตอนเปิดใช้ครั้งแรก {#first-run-choice}

เมื่อผู้ดูแลระบบเปิดอินสแตนซ์ใหม่เป็นครั้งแรก SnapOtter จะถามว่า "ส่งสถิติการใช้งานแบบไม่ระบุตัวตนและรายงานข้อขัดข้องหรือไม่? ไฟล์ของคุณจะไม่ถูกส่งออกไปเลย" คำตอบทั้งสองมีน้ำหนักเท่ากันและไม่มีข้อใดถูกเลือกไว้ล่วงหน้า หากปิดข้อความโดยไม่ตอบ การวิเคราะห์จะยังคงปิดอยู่และจะถามอีกครั้งในการเข้าใช้ครั้งถัดไป เฉพาะผู้ดูแลระบบเท่านั้นที่เห็น เมื่อใช้ `AUTH_ENABLED=false` จะไม่มีบัญชีผู้ใช้และผู้ใช้ภายในเครื่องทำหน้าที่เป็นผู้ดูแลระบบ ดังนั้นใครก็ตามที่เปิดแอปจะเป็นผู้ตอบ แอปเดสก์ท็อปถามในลักษณะเดียวกัน

อินสแตนซ์ที่ทำงานอยู่ก่อนที่จะมีข้อความนี้จะไม่ถูกถาม โดยจะคงการตั้งค่าการวิเคราะห์เดิมไว้ คือเปิดอยู่ เว้นแต่ผู้ดูแลระบบหรือ `SNAPOTTER_ANALYTICS_DEFAULT=off` จะปิดไว้

## เหตุการณ์ที่เราส่ง (เมื่อเปิดใช้งาน) {#events-we-send-when-enabled}

- tool_used: ID ของเครื่องมือ สถานะ ระยะเวลา หมวดหมู่ เป็นเครื่องมือ AI หรือไม่ และรหัสข้อผิดพลาดเมื่อล้มเหลว
- pipeline_executed: จำนวนขั้นตอน ID ของเครื่องมือ แฟล็กแบตช์ จำนวนไฟล์ ระยะเวลา สถานะ
- ai_bundle_action: ID ของชุดแพ็กเกจ การดำเนินการ ระยะเวลา
- การใช้งานฝั่ง frontend: หน้าเครื่องมือใดที่ถูกเปิด ไฟล์ที่เพิ่ม (เฉพาะจำนวน) เครื่องมือที่เริ่มทำงาน การดาวน์โหลด การบันทึก การค้นหา (เฉพาะจำนวนผลลัพธ์) แบตช์ที่ประมวลผลแล้ว
- รายงานข้อขัดข้อง: ประเภทข้อผิดพลาด ข้อความข้อผิดพลาดที่ปกปิดข้อมูลแล้ว (ตัดชื่อไฟล์ พาธ อีเมล และค่าที่อยู่ในเครื่องหมายคำพูดออก) สแตกต้นทางที่มีเฉพาะชื่อฐานของไฟล์ และสำหรับเครื่องมือ AI จะมี Python traceback ที่มีเฉพาะชื่อฐานของไฟล์

## สิ่งที่เราไม่เก็บเลย {#what-we-never-collect}

- ชื่อไฟล์หรือพาธ
- เนื้อหาในไฟล์
- ข้อความผลลัพธ์ OCR
- เมทาดาทาของรูปภาพ (EXIF)
- ข้อความที่ดึงออกจากเอกสาร
- ตัวตนบัญชีของคุณ

PostHog เห็นที่อยู่ IP ที่แต่ละคำขอส่งมา เช่นเดียวกับเซิร์ฟเวอร์ทั่วไป โปรเจกต์ PostHog ของเราทิ้งที่อยู่นั้นแทนที่จะจัดเก็บ และเหตุการณ์จากเซิร์ฟเวอร์ของ SnapOtter เองจะส่งค่าตัวแทนไปแทน

## การแจ้งเตือนอัปเดต {#update-notices}

ขณะที่เปิดการวิเคราะห์ เซิร์ฟเวอร์จะถาม PostHog ทุกไม่กี่ชั่วโมงว่า SnapOtter รุ่นใดใหม่ที่สุด โดยใช้ ID แบบไม่ระบุตัวตนของอินสแตนซ์และเวอร์ชันของมัน เมื่อมีรุ่นที่ใหม่กว่า ผู้ดูแลระบบจะเห็นการแจ้งเตือนพร้อมลิงก์ไปยังบันทึกการออกรุ่น หากปิดการแจ้งเตือน มันจะถูกซ่อนไว้จนกว่าจะมีรุ่นถัดไป ระบบจะไม่ติดตั้งหรือดาวน์โหลดอะไรให้คุณ และเมื่อปิดการวิเคราะห์ เซิร์ฟเวอร์จะไม่ถามเลย

## การปิดใช้งาน {#turning-it-off}

ผู้ดูแลระบบ: ไปที่ Settings > System > Privacy แล้วปิด "Anonymous Product Analytics" การส่งจะหยุดทันทีทั้งอินสแตนซ์ หากต้องการสร้างอิมเมจที่ไม่มีวันส่งข้อมูลได้ ให้ตั้งค่า build arg `SNAPOTTER_ANALYTICS=off` การตั้ง `SNAPOTTER_TELEMETRY=off` ในสภาพแวดล้อมของเซิร์ฟเวอร์ให้ผลเหมือนกันขณะรันและมีผลเหนือกว่าคำตอบใดๆ ที่บันทึกไว้ในแอป

หากต้องการตอบคำถามตอนเปิดใช้ครั้งแรกล่วงหน้า ให้เพิ่ม `SNAPOTTER_ANALYTICS_DEFAULT=off` (หรือ `on`) ลงในสภาพแวดล้อมของเซิร์ฟเวอร์ก่อนบูตครั้งแรก แล้วจะไม่มีใครถูกถาม เมื่อใช้ Docker Compose ให้ใส่ไว้ใต้ `environment:` ของบริการแอป เพราะการตั้งค่าไว้ใน `.env` เพียงอย่างเดียวจะไม่ส่งถึงคอนเทนเนอร์
